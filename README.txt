# دعوة خطوبة الدكتور عبدالقادر & المهندسة نور

تم تصميم هذه الدعوة الفاخرة خصيصاً لتتوافق مع أرقى التصاميم العالمية وتتضمن كافة التفاصيل المطلوبة بدقة عالية وأناقة فائقة.

## محتويات ملف الـ ZIP:
1. `index.html`: ملف الصفحة الرئيسية الكامل الذي يحتوي على كافة التفاصيل، الأقسام، المؤثرات التفاعلية، شاشة الغلاف بختم ذهبي، رسوم متحركة للورود البيضاء والحمامات عند الفتح، عد تنازلي، برنامج الحفل، والموقع.
2. `your-song.mp3`: مكان مخصص لإضافة ملف الأغنية الخاص بك (قم باستبدال هذا الملف أو وضع ملف الأغنية بنفس الاسم في نفس المجلد).

## تعليمات إضافة الأغنية:
- قم بوضع ملف الأغنية بصيغة `.mp3` في نفس المجلد وسمّه `your-song.mp3` أو قم بتعديل اسم الملف في وسم `<source src="your-song.mp3" type="audio/mpeg">` داخل ملف `index.html`.
